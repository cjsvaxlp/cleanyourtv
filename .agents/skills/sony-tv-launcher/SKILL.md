# 港岛时光桌面

本仓库 `launcher/` 是用户电视正在使用的定制源码。继续修改这一份，不用上游原版或旧分享包替换。上游：https://github.com/Gathin23/cleanyourtv 。

## 有效需求

- 原生 Android View 实现轻量透明玻璃；不引入 Compose、Backdrop 或其他玻璃效果包。
- 顶部三个按钮保留文字、图标、玻璃背景及淡边框。聚焦时中性色略加深，可约 1.02 倍缩放、140ms 过渡；无蓝色细框、彩色光圈或文字描边。背景状态切换不使用会遗留透明状态的淡入淡出。
- 浅色模式减少发白的按钮和固定栏底色，突出透明度；白天壁纸清晰，无白色蒙版。夜间固定应用聚焦光影克制。应用库与操作菜单适配深浅主题。
- “简洁桌面设置”内用并排选项卡选择深色、浅色、自动，不用选择弹框；位置在“跟随主题（重置电视端设置）”上方。移除 Module cards 入口并默认关闭。
- 默认自动主题：Asia/Hong_Kong，06:00 浅色，19:00 深色；手动主题选择应保留。
- 首页问候语、日期固定英文，正常首字母大小写，例如 Good morning、Good evening，不用全大写。
- 首页首屏只显示四个固定应用，其他应用向下访问，不露出下一行。保留用户现有顺序；从电视实际配置读取，不能拿示例配置覆盖。
- 应用长按可方便添加到固定栏；满四个时选择替换，已固定可移除。使用紧凑玻璃菜单，避免旧式大弹框。
- 应用库同时识别 TV 和普通安卓启动入口。帮助、应用中心、应用助手、生活空间装饰、节能控制面板、计时器和时钟、音乐、My Sony 会员、通知等低频应用收纳到应用库；收纳不等于停用或卸载。
- 保留蓝莓投屏的默认使用配置；内置投屏是否卸载需另外处理，不能据此自行删除系统组件。
- 不恢复已取消的 Web 远程推送功能。

## 壁纸需求与当前实现

用户希望香港岛、坚尼地城、迪士尼、山顶等实景摄影，保留摄影来源和许可信息。壁纸是外置静态文件，不打进 APK。

目标算法：浅色只选日景组，深色只选夜景组；按各组实际张数均分对应时段，增减图片后重新计算，不每10分钟或随机换图。算法和当前固定时间表见 [壁纸说明](references/wallpaper.md)。当前个人版本尚不是通用动态分组算法，不要将旧分享版的实现状态套用到本仓库。

## 构建和更新

读取 [构建与电视配置](references/build-and-tv.md) 后执行相应步骤。只编译用户要求的修改，验证通过后再覆盖安装；无需每个小改动都单独打包。

不要卸载或清数据；保留配置、固定应用、应用库选择和壁纸。不同签名不得通过卸载绕过。签名私钥和电视配置不随公共 PR 上传。用户调试期间要求保持调试开启。

检验实际深浅主题切换后顶部按钮的背景、文字和图标，应用库、长按菜单、首页首屏及遥控器操作。预览结束清除 preview_theme 启动参数，恢复测试前的用户主题选择。构建通过与电视实测分别报告，不把未实现的需求说成已完成。
