# 港岛时光桌面

本仓库 `launcher/` 是用户电视正在使用的定制源码。继续修改这一份，不用上游原版或旧分享包替换。上游：https://github.com/Gathin23/cleanyourtv 。

## 有效需求

- 原生 Android View 实现轻量透明玻璃；不引入 Compose、Backdrop 或其他玻璃效果包。
- 顶部三个按钮保留文字、图标、玻璃背景及淡边框。聚焦时中性色略加深，可约 1.02 倍缩放、140ms 过渡；无蓝色细框、彩色光圈或文字描边。背景状态切换不使用会遗留透明状态的淡入淡出。
- 浅色模式减少发白的按钮和固定栏底色，突出透明度；白天壁纸清晰，无白色蒙版。夜间固定应用聚焦光影克制。应用库与操作菜单适配深浅主题。
- “简洁桌面设置”内用并排选项卡选择深色、浅色、自动，不用选择弹框；位置在“跟随主题（重置电视端设置）”上方。移除 Module cards 入口并默认关闭。
- 默认自动主题：Asia/Hong_Kong，06:00 浅色，19:00 深色；手动主题选择应保留。
- 首页问候语、日期固定英文，正常首字母大小写，例如 Good morning、Good evening，不用全大写。
- 首页首屏只显示四个固定应用，其他应用向下访问，不露出下一行。保留用户现有顺序；从电视实际配置读取，不能拿示例配置覆盖。
- 应用长按可方便添加到固定栏；满四个时选择替换，已固定可移除。使用紧凑玻璃菜单，避免旧式大弹框。
- 应用库同时识别 TV 和普通安卓启动入口。帮助、应用中心、应用助手、生活空间装饰、节能控制面板、计时器和时钟、音乐、My Sony 会员、通知等低频应用收纳到应用库；收纳不等于停用或卸载。
- 保留蓝莓投屏的默认使用配置；内置投屏是否卸载需另外处理，不能据此自行删除系统组件。
- 不恢复已取消的 Web 远程推送功能。

## 壁纸需求与当前实现

用户希望香港岛、坚尼地城、迪士尼、山顶等实景摄影。首页不显示摄影照片署名、地点或说明；来源与许可留在配套文件。壁纸是外置静态文件，不打进 APK。

当前要求（2026-10-22）：白天浅色壁纸规则保持原样；夜景仅在19:00–00:00显示，按实际夜景张数平分300分钟；00:00–06:00不显示壁纸，显示纯深色背景。夜景识别 hk-night* 或 dark-* 文件名，按字典序。顶部和首页应用库按钮共用同一默认透明玻璃及中性加深聚焦样式，不使用聚焦白块或蓝框。修改、构建直接在本项目完成，不另建源码副本。模拟器需将本桌面设为默认HOME，不能仅安装后启动一次。


## 官方更新与构建要求

- 每次后续部署前，检查上游官方仓库的新增提交、发布说明及相关源码，向用户简要说明相对本定制版新增了哪些功能；检查日期及对照提交应可追溯。只检查更新不等于自动合并，不用上游版本覆盖定制功能。
- 如果官方新增或完善了壁纸、日夜主题、深浅色主题能力，在构建前明确通知用户，说明官方支持范围及与当前定制功能的差异。先核对源码，不仅凭发布标题判断，也不要把上游原已有的基础壁纸支持说成新增功能。网络无法访问时说明未能完成检查，不声称已是最新。
- 用户要求后续构建只保留英文界面：移除非英文语言资源，检查默认 values、运行时硬编码文字及格式化逻辑均为英文；配置 Android 资源语言过滤以避免依赖库带入其他语言。不得删除非语言资源、字体或图片，也不要误删 values-night、values-vXX 等仅按显示条件限定的资源。中文系统下仍应显示英文，应用名称可保留各应用自身名称。
- 2026-10-22 已在官方 v2.6.0 合并预览版中移除非英文资源，加入 en 资源过滤并翻译运行时定制文字；已构建及在 Android TV 模拟器预览，尚未部署到用户电视。

## 构建和更新

读取 [构建与电视配置](references/build-and-tv.md) 后执行相应步骤。只编译用户要求的修改，验证通过后再覆盖安装；无需每个小改动都单独打包。

不要卸载或清数据；保留配置、固定应用、应用库选择和壁纸。不同签名不得通过卸载绕过。签名私钥和电视配置不随公共 PR 上传。用户调试期间要求保持调试开启。

检验实际深浅主题切换后顶部按钮的背景、文字和图标，应用库、长按菜单、首页首屏及遥控器操作。预览结束清除 preview_theme 启动参数，恢复测试前的用户主题选择。构建通过与电视实测分别报告，不把未实现的需求说成已完成。

## 模拟器验证环境

使用 Television_1080p 模拟器；启动后先核对真实日期、时间、时区及自动校时，不能把旧快照的时间当作现实时间。用户在上海，模拟器用 Asia/Shanghai；程序现有 Asia/Hong_Kong 与上海同为UTC+8，无需为此改动壁纸算法。2026-10-22发现旧快照停在9月25日凌晨，已校正并保持自动校时开启。

默认HOME应为 com.gathin.tvhome/.MainActivity。模拟器原 com.google.android.tvlauncher 有系统优先级，已仅在模拟器停用原桌面并保留安装包；恢复可执行 pm enable --user 0 com.google.android.tvlauncher。保存包含最新安装包、主题文件、正确时间及默认HOME的default_boot快照；下次启动仍需核对时间，不能假定自动同步成功。上述操作不适用于用户实体电视。
